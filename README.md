# System Design Dictionary

A visual learning site for system-design fundamentals. Each concept opens at its own shareable URL with:

- a plain-English definition;
- why the pattern exists;
- practical use cases and trade-offs;
- a concrete example; and
- an interactive diagram where each component is clickable.

It also includes interview case studies for Ride Hailing (Design Uber), URL Shortener, Chat, and
Notification System. Each case follows an interview-ready sequence: requirements, scope, scale,
contracts, data model, architecture, critical flow, trade-offs, failures, and follow-up questions.

## Included concepts

60 foundational concepts across traffic routing, networking, caching, asynchronous processing,
distributed data, reliability, architecture, scaling, and operations.

## Run locally

Open `index.html` in a browser. No framework, build step, or dependency installation is required.

## Publish with GitHub Pages

Push these files to a repository, then enable **Settings → Pages → Deploy from a branch** and choose `main` / root.
